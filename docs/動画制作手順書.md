# 動画制作手順書

video-studio でショート動画を 1 本作る手順をまとめます。環境の用意は [README](../README.md) を先に済ませてください。

---

## 全体の流れ

| # | ステップ | 担当の例 | ツール |
|---|---|---|---|
| 1 | 作業フォルダを作る | 人 / AI | シェル |
| 2 | 台本を書く | AI | Claude Code など |
| 3 | 映像生成用のプロンプトを書く | AI | Claude Code など |
| 4 | ナレーション音声を作る | 人 / AI | VOICEVOX |
| 5 | 映像クリップを作る | 人 | Google Flow など |
| 6 | 画面録画をする | 人 | OS 標準の録画など |
| 7 | `video.config.json` を書く | 人 / AI | エディタ |
| 8 | プレビューで確認・調整する | 人 | Remotion Studio |
| 9 | 書き出す | 人 | Remotion |

映像クリップ（5）や画面録画（6）が不要な動画は、飛ばして構いません。素材なしで描画できる最小の例は `examples/sample/` にあります。

---

## フォルダの規則

```
works/YYYY-MM-DD_タイトル/
├── video.config.json   # 動画の設定（タイミング・字幕・素材のパスをすべて定義）
├── 01_script.md        # 台本（任意。ナレーション・字幕・構成のメモ）
├── 02_flow-prompts.md  # 映像生成用のプロンプト（任意）
├── audio/              # ナレーション音声（この動画だけで使う）
│   ├── 01_hook.wav
│   └── 02_main.wav
└── assets/             # 画面録画など（この動画だけで使う）
    └── screen_demo.mp4

assets/                 # 複数の動画で共有する素材（各自で用意。中身は Git 管理外）
├── bgm/                # BGM（mp3）
├── clips/              # 映像クリップ（mp4）
└── images/             # ロゴなどの画像（png）
```

### 素材の名前の付け方

| 種類 | 規則 | 例 |
|---|---|---|
| 映像クリップ | 内容を英語で表す | `city-night-timelapse.mp4` |
| BGM | 雰囲気を英語で表す | `bgm-calm-piano.mp3` |
| 画面録画 | `screen_` を付ける | `screen_demo.mp4` |
| 音声 | 連番 + セクション名 | `01_hook.wav` |

## ステップの詳細

### 1. 作業フォルダを作る

```bash
mkdir -p works/$(date +%Y-%m-%d)_タイトル/{audio,assets}
```

### 2. 台本を書く

次の内容を含めておくと、あとの工程が楽になります。

- 各セクションのナレーション
- 字幕（テロップ）の文章
- 想定の秒数（音声を作ったあとで実測値に直します）
- どの映像を使うかのメモ

セクションの例です。

| セクション | 目的 | 目安の長さ |
|---|---|---|
| hook | 注意を引く・問題提起 | 〜8 秒 |
| main | 本題の説明 | 〜25 秒 |
| cta | 行動の呼びかけ | 〜8 秒 |
| disclaimer | 免責・出典 | 〜3 秒 |

### 3. 映像生成用のプロンプトを書く

AI 動画生成サービスを使う場合のメモです。

- サービスごとに 1 クリップの長さに上限があります（例: Google Flow の Veo 3.1 は最大 8 秒）。短いクリップは設定ファイルの `loop: true` で延ばせます。
- 縦型 9:16（1080×1920）であることをプロンプトに明記します。
- 画面録画が主役のセクションには、生成クリップは不要です。冒頭や締めの短い区間、背景のオーバーレイに使うと効果的です。

### 4. ナレーション音声を作る（VOICEVOX）

```bash
make up   # 起動していなければ

# セクションごとに音声を生成（SPEAKER は話者のスタイル ID。一覧は make voicevox-speakers）
make voicevox-gen \
  TEXT="ナレーションのテキスト" \
  OUT=works/YYYY-MM-DD_タイトル/audio/01_hook.wav \
  SPEAKER=3
```

生成したら、実際の長さを測って台本の秒数を直します。

```bash
docker compose -f docker/docker-compose.yml exec remotion ffprobe -v quiet \
  -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 \
  works/YYYY-MM-DD_タイトル/audio/01_hook.wav
```

### 5. 映像クリップを用意する

1. プロンプトを映像生成サービスに貼り付けて生成します。
2. できたクリップを `assets/clips/` に保存します（名前の付け方は上の表）。

### 6. 画面録画をする

- 解像度はできるだけ高く（1080p 以上）します。
- 録画ファイルは `works/YYYY-MM-DD_タイトル/assets/` に保存します。

### 7. video.config.json を書く

`examples/sample/video.config.json` か、過去の作品の設定をコピーして編集します。**Remotion のコードを変える必要はありません。**

```bash
cp examples/sample/video.config.json works/YYYY-MM-DD_タイトル/video.config.json
```

各項目の意味は [video.config.json リファレンス](video-config.md) を参照してください。

#### セクション構成の例

| `layers` の区間 | 使う素材 | 備考 |
|---|---|---|
| hook〜problem | 映像クリップ | `loop: true` |
| main 前半 | 画面録画 | |
| main 後半 | 画面録画 + 映像クリップのオーバーレイ | `opacity: 0.25` |
| cta | 映像クリップ | `loop: true` |
| 最後 | レイヤーなし | エンドカード（黒背景） |

#### 秒数の決め方

各セクションの `startSec` は、直前のセクションが終わる秒数（= そのセクションの音声が始まるタイミング）です。音声の長さは ffprobe の実測値を使ってください。

#### 広告向けの短い尺

`durationSec` を短くするだけで、尺は自由に変えられます。6 秒のバンパー広告のように免責の表示時間をほとんど取れない場合は、`persistentDisclaimer` を設定して、動画全体に免責を出し続けます。

| 尺 | 構成の目安 | `persistentDisclaimer` |
|---|---|---|
| 6 秒（バンパー） | フック 1 カット + ロゴ + 一言の呼びかけ | 動画全体に常時表示 |
| 15 秒 / 30 秒 | hook + main + 簡単な cta | エンドカードの手前まで常時表示 |

6 秒の例です（素材のパスは各自の素材に読み替えてください）。

```json
{
  "id": "AdBumper_Sample_01",
  "fps": 30,
  "width": 1080,
  "height": 1920,
  "durationSec": 6,
  "persistentDisclaimer": "※ 内容は例示であり、効果を保証するものではありません",
  "bgm": { "path": "current/bgm/bgm-calm-piano.mp3", "volume": 0.2 },
  "layers": [
    { "type": "video", "path": "current/clips/city-night-timelapse.mp4", "startSec": 0, "endSec": 6, "volume": 0, "loop": true }
  ],
  "audioTracks": [
    { "startSec": 0, "path": "current/audio/01_hook_short.wav" }
  ],
  "subtitles": [
    { "startSec": 0, "endSec": 4.5, "text": "一言で伝わる\nキャッチコピー" }
  ],
  "endcard": {
    "startSec": 4.5,
    "mainText": "サービス名",
    "ctaText": "↓ 詳しくはこちら",
    "disclaimerText": "※ 内容は例示であり、効果を保証するものではありません",
    "logoPath": "current/images/logo.png"
  },
  "logoMini": { "path": "current/images/logo-mini.png", "ranges": [] }
}
```

`persistentDisclaimer` は `endcard.startSec`（この例では 4.5 秒）まで表示され、その後は `endcard.disclaimerText` が引き継ぎます。

### 8. プレビューで確認する

```bash
# 素材を remotion/public/current/ に取り込む（WORK を省略すると最新の作業フォルダ）
make copy-assets WORK=works/YYYY-MM-DD_タイトル

# Remotion Studio を起動
make studio
# → http://localhost:3000 で、作品の ID の Composition を選んで確認
```

Studio の Props パネルから `video.config.json` の内容を直接編集して、すぐにプレビューできます。

### 9. 書き出す

```bash
# 設定ファイルから書き出し（copy-assets も自動で実行します）
make render-work WORK=works/YYYY-MM-DD_タイトル

# 出力先: output/YYYY-MM-DD_タイトル.mp4
```

## コマンドの早見表

```bash
make up                                                        # コンテナの起動
make down                                                      # コンテナの停止
make voicevox-gen TEXT="..." OUT=works/.../audio/01_hook.wav SPEAKER=3   # 音声生成
make voicevox-speakers                                         # 話者の一覧
make copy-assets WORK=works/YYYY-MM-DD_タイトル                # 素材の取り込み
make generate-registry                                         # Composition 一覧の再生成
make studio                                                    # Remotion Studio
make render-work WORK=works/YYYY-MM-DD_タイトル                # 設定ファイルから書き出し
make render COMP=Sample OUT=output/xxx.mp4                     # Composition の ID を指定して書き出し
```

## よくあるトラブル

| 症状 | 原因 | 対処 |
|---|---|---|
| 映像が表示されない | `public/current/` に素材がない | `make copy-assets WORK=...` を実行する |
| 音声がずれる | `audioTracks[].startSec` が実測値と違う | `ffprobe` で測り直して JSON を更新する |
| Studio に Composition が出ない | レジストリが古い | `make copy-assets WORK=...` か `make generate-registry` を実行する |
| Studio や書き出しが `registry.json` を見つけられない | レジストリ（`remotion/src/registry.json`）が未生成 | `make generate-registry` を実行する（`make studio` と `make render` は、無ければ自動で生成します） |
| `docker network` のエラー | ネットワーク名の不一致 | `make up` がネットワーク `docker_default` を作ります。手動で作る場合は `docker network create docker_default` |
| 映像クリップが短い | 生成サービスの長さの上限 | `loop: true` で延長する |
| `apt-get` が失敗してビルドできない | ベースイメージの Debian が古い | `docker/remotion/Dockerfile` の `FROM` を、サポート中の Debian（現在は bookworm）にする |

## BGM の選び方

BGM は配布サイトの規約を確認して、各自で用意します。このリポジトリには同梱していません。

- 音量は `volume: 0.3` 前後から始めて、ナレーションとのバランスで調整します。
- 音源ファイルの再配布を禁止しているサイトがあるため、BGM を公開リポジトリにコミットしないでください（`assets/bgm/` の中身は `.gitignore` で除外されています）。
